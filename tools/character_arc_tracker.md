# character_arc_tracker

## Purpose

Character Arc Tracker monitors every major character's transformation across the serialization.

Static characters kill long-form fiction.

Forgotten character traits kill credibility.

This tool makes growth visible and drift detectable.

---

## When To Use

- At architecture stage (define arcs)
- Every 10 chapters (update arcs)
- When a character feels flat
- Before a major character scene

---

## Arc Definition Card

For every major character:

| Field | Value |
|-------|-------|
| Name | |
| Role | Protagonist / Ally / Rival / Antagonist / Foil |
| Starting State | Belief + behavior at story start |
| Goal | What they want |
| Motivation | Why they want it |
| Fear | What they avoid |
| Weakness | What defeats them |
| Core Flaw | The flaw the arc will challenge |
| Ending State (planned) | Belief + behavior at arc end |
| Change Driver | Events that force change |

---

## Change Event Log

Every meaningful change must be logged:

| Chapter | Event | Old State | New State | Why Now | Cost Paid |
|---------|-------|-----------|-----------|---------|-----------|
| | | | | | |

A change without a logged cause is a plot hole.

A change without a cost is a cheat.

---

## Arc Health Checks

### Check 1 — Movement

Has the character changed in the last 30 chapters?

If no:

Flag: STATIC

### Check 2 — Causality

Is every change caused by an on-page event?

If no:

Flag: UNMOTIVATED

### Check 3 — Consistency

Does current behavior contradict Starting State without a logged Change Event?

If yes:

Flag: DRIFT

### Check 4 — Cost

Does every power-up or status gain carry a cost or obstacle?

If no:

Flag: CHEAT

### Check 5 — Contrast

Do allies and rivals have arcs that oppose or mirror the protagonist?

If no:

Flag: FLAT SUPPORTING CAST

---

## Antagonist Tracking

Antagonists need arcs too.

Track:

- Their goal
- Their justification (why they believe they are right)
- Their escalation path
- Their relationship shift with the protagonist
- Their defeat conditions

---

## Output Format

# Arc Overview

Table: Character | Starting State | Current State | Planned End | Health Flag

# Change Event Log

Full log since last review

# Problem Characters

- Name
- Flag (STATIC / UNMOTIVATED / DRIFT / CHEAT / FLAT)
- Evidence (chapter + quote)
- Fix instruction

# Next Change Points

Planned events for the next 10 chapters

---

## Rule

Review all arcs every 10 chapters.

Static characters are allowed for exactly one purpose:

Comic relief.

Everyone else must move.
