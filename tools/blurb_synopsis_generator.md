# Blurb & Synopsis Generator

Platform listing copy that converts scrollers into chapter-1 clicks.

## When to use

- After Golden Three GO and before `tools/submission_checklist.md`
- When comparing 2–3 title variants with their matching blurbs
- When a platform form asks for 一句话简介 / 简介 / 标签 / 卖点

## Inputs required

| Field | Notes |
|-------|--------|
| Working title | 1 primary + 2 alternates |
| Genre & platform | Use the matching `knowledge/submit_*.md` pack |
| Core engine | From Planner: wish / power loop / emotional payoff |
| Golden hook | The chapter-1 open-loop in one sentence |
| Protagonist want | Concrete goal, not archetype label |
| Stakes | What fails if they stop reading |

## Output pack

Produce **one block per title variant** in this order:

### A. One-line pitch (≤ 20 Chinese characters)

Formula: `[身份/处境] + [异常入口] + [欲望/后果]`

Bad: 一个少年的逆袭之路  
Good: 废柴觉醒签到系统，每天白捡一年修为  

### B. Short blurb (≤ 80 characters)

Must contain: entry event → immediate ability/value → first concrete win tease.  
No world-history dump. No theme lectures.

### C. Long synopsis (150–300 characters)

Structure (4 beats):

1. **Normal world broken** — 1 short sentence  
2. **Abnormal entry** — the system / return / cheat / corpse  
3. **First cash-in** — one measurable win in chapter 1–3  
4. **Open loop** — the next irresistible question  

Platform notes:

- **番茄 / 七猫**: punchier verbs, higher wish density, shorter sentences  
- **起点**: allow slightly denser setting, still front-load the golden hook  
- **晋江**: emotional relationship stakes in beat 3–4 when genre fits  

### D. Tag pack (5–8)

Order: 品类大词 → 金手指/设定 → 爽点类型 → 情绪/关系 → 避雷反选（可选）

### E. Title–blurb fit score (1–5)

| Score | Meaning |
|------|---------|
| 5 | Title promise = blurb payoff = chapter-1 event |
| 3 | Same genre, loose promise alignment |
| 1 | Title and blurb sell different books |

If score ≤ 3, rewrite the weaker of the two before submission.

## Hard rules

- Never spoil the mid-book twist in the public blurb  
- Keep numbers consistent with `tools/story_bible.md`  
- Prefer concrete nouns over abstract virtue words  
- Chinese web-fiction voice: direct, visual, high-frequency reward words  

## Hand-off

Copy the winning variant into `tools/submission_checklist.md` metadata fields:  
`title`, `one_liner`, `short_blurb`, `long_synopsis`, `tags`.
