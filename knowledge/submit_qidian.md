# submit_qidian

## Purpose

Submission constraints and review culture for Qidian (起点中文网) male-frequency web fiction.

Use when the target platform is Qidian or a close derivative.

---

## When To Use

After submission_checklist gate 1-3 pass.

Before opening the Qidian author backend create-work form.

---

## Form Fields That Matter

| Field | Constraint | Notes |
|-------|------------|-------|
| 书名 | Usually 2-8 Chinese characters preferred; longer allowed if punchy | Avoid pure English |
| 分类 | Must match the actual content weight | Wrong class kills recommendation |
| 标签 | Limited count; pick identity + genre + hook | Do not spam trending tags |
| 简介 | Short paragraphs; first line is the hook | Mobile truncates early |
| 首发状态 | Affects recommendation eligibility | Prefer true first publish if possible |

---

## Title Fit

Qidian rewards identity-advantage and concrete power nouns.

Good patterns: 我 + 金手指 / 从 + 身份 + 开始 / 全球 + 灾变 + 我

Avoid: vague poetic titles without a readable promise.

---

## Synopsis Craft

- Line 1: protagonist status or loss
- Line 2: the system / cheat / rebirth event
- Line 3: the first major goal
- Keep under ~120 Chinese characters when possible
- No marketing adjectives

---

## First Chapter Bar

Open inside a scene, not a world tour.

State the disadvantage within the first screen.

Deliver the first small payoff before the chapter ends.

---

## Review Risks

- Content policy: no real-politics, no banned supernatural claims presented as fact
- Category mismatch: urban system filed as fantasy will fail or underperform
- Copycat titles in a hot category during the same week

---

## Update Expectations

Qidian readers punish silent drops.

Publishing calendar safety line matters more here than on short-form apps.

Pair with tools/publishing_calendar.md.

---

## Output Checklist

- [ ] Title under platform norms and scored
- [ ] Category matches power system and setting
- [ ] Synopsis three-sentence formula applied
- [ ] Launch batch >= 3 chapters with hooks
- [ ] Next 3 update dates fixed
