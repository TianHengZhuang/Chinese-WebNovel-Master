# Game Genre Patterns

## Audience

Primary Readers:

* Male 14-30
* Gamers and system-flow fans
* Readers who enjoy visible progression and rules

---

## Core Reader Expectations

### The Panel

System-flow readers expect a visible status layer:

- Attribute panel
- Skill list
- Quest log
- Inventory
- Achievement / title system

Panel updates are payoffs:

Do not spam numbers.

Show the panel only when something meaningful changes.

---

## Sub-Variants

| Variant | Core Loop |
|---------|-----------|
| Full-dive game | Enter a game world, clear it, or survive it |
| System intrusion | Game panel invades reality |
| Game + reality | Compete in a game that affects real life |
| Dungeon outbreak | Dungeons appear in the modern world |
| Esports | Competitive play, team growth, titles |

---

## Progression Architecture

### Level Rhythm

- Fast early levels (visible gain every 1-3 chapters)
- Slower mid levels (gains every 5-8 chapters, with skill unlocks)
- Endgame prestige (rebirth / new system layer)

### Quest Chains

Quests must form chains:

Main quest (arc goal)

→ Branch quests (world discovery)

→ Hidden quests (mystery + reward)

Never present isolated fetch quests as plot.

### Cost Mechanics

Progression requires costs:

- Money
- Materials
- Reputation
- Time
- Risk

A system that costs nothing destroys tension.

---

## Boss Design

Every major boss needs:

- Visible strength (why everyone fears it)
- A mechanic (why brute force alone fails)
- A weakness discoverable in prior chapters
- A reward that changes the story (not just stats)

---

## Platform Fit

| Platform | Strategy |
|----------|----------|
| Tomato | System intrusion, fast loops, chapter-hook quests |
| Qidian | Full-dive + kingdom building, long progression |
| Feilu | Supremacy fantasy, skill build creativity |
| Boluobao | Light-novel game comedy, party dynamics |

---

## Pacing Notes

- One visible gain per 1-3 chapters at minimum
- Level-up alone is not a payoff: attach a story consequence
- Skill builds should feel personal (reader defends the build choice)

---

## Hook Formulas

* 全服第一玩家重生回开服前一天
* 系统只发任务，而每个任务都在预言现实灾难
* 副本怪物来到现实，只有玩家能看见它们
